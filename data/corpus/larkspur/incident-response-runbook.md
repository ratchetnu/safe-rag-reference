# Security Incident Response Runbook

## Severity levels

Incidents are classified from SEV1 (most severe) to SEV4. A SEV1 incident involves confirmed data exposure or a full outage of a customer-facing system.

## Paging

For a SEV1 incident, page the security on-call engineer within 15 minutes of detection. For SEV2, page within 1 hour.

## Incident bridge

The incident bridge code is BRIDGE-ORCHID-4471. Share the bridge code only with responders assigned to the incident.
